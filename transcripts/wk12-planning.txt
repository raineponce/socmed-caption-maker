     │ Plan: Social Media Caption Generator (Ollama + HTML)                    │
     │                                                                         │
     │ Context                                                                 │
     │                                                                         │
     │ Build a single-page HTML tool for a school project (DIG4503). The user  │
     │ pastes an article into the UI, and a local Ollama LLM generates         │
     │ platform-appropriate social media captions and ranked hashtags. Caption │
     │  style examples are entered in the UI so the LLM can match tone and     │
     │ format.                                                                 │
     │                                                                         │
     │ Requirements Summary                                                    │
     │                                                                         │
     │ - Single index.html file (no backend, no build step)                    │
     │ - Calls Ollama's local REST API at http://localhost:11434               │
     │ - Model: Gemma 4 (Ollama tag likely gemma3 or gemma4 — expose as        │
     │ editable field in UI)                                                   │
     │ - Output per generation:                                                │
     │   - 1 long-form caption for Instagram / Facebook / LinkedIn             │
     │   - 1 short caption for Twitter/X (≤280 chars)                          │
     │   - 20 hashtags sorted by estimated popularity (most-used first)        │
     │ - Caption style/tone is guided by user-provided examples typed into the │
     │  UI                                                                     │
     │                                                                         │
     │ ---                                                                     │
     │ File to Create                                                          │
     │                                                                         │
     │ index.html (project root)                                               │
     │                                                                         │
     │ ---                                                                     │
     │ Implementation Plan                                                     │
     │                                                                         │
     │ 1. HTML Structure                                                       │
     │                                                                         │
     │ Three input sections + one output section:                              │
     │                                                                         │
     │ ┌─────────────────────────────────────┐                                 │
     │ │  ⚙ Model name  [gemma3          ]   │                                 │
     │ ├─────────────────────────────────────┤                                 │
     │ │  📋 Caption Examples                │                                 │
     │ │  [paste 2–5 example captions here]  │                                 │
     │ ├─────────────────────────────────────┤                                 │
     │ │  📰 Article                         │                                 │
     │ │  [paste article text here         ] │                                 │
     │ ├─────────────────────────────────────┤                                 │
     │ │  [Generate Captions]                │                                 │
     │ ├─────────────────────────────────────┤                                 │
     │ │  Instagram / Facebook / LinkedIn    │                                 │
     │ │  [generated caption]                │                                 │
     │ │                                     │                                 │
     │ │  Twitter / X                        │                                 │
     │ │  [generated caption]                │                                 │
     │ │                                     │                                 │
     │ │  Hashtags (ranked by popularity)    │                                 │
     │ │  #tag1  #tag2  #tag3 ...            │                                 │
     │ └─────────────────────────────────────┘                                 │
     │                                                                         │
     │ 2. Ollama API Call                                                      │
     │                                                                         │
     │ - Endpoint: POST http://localhost:11434/api/generate                    │
     │ - Payload: { model, prompt, stream: false }                             │
     │ - Handle errors (Ollama not running, model not found)                   │
     │                                                                         │
     │ 3. Prompt Design                                                        │
     │                                                                         │
     │ Use a structured prompt that instructs the model to return clearly      │
     │ delimited sections so parsing is reliable:                              │
     │                                                                         │
     │ You are a social media copywriter. Here are example captions for        │
     │ reference:                                                              │
     │ {examples}                                                              │
     │                                                                         │
     │ Based on the following article, generate:                               │
     │ 1. LONG_FORM: A caption for Instagram, Facebook, and LinkedIn. Match    │
     │ the style and tone of the examples. Can include line breaks and up to 5 │
     │  hashtags inline.                                                       │
     │ 2. TWITTER: A caption for Twitter/X. Must be under 280 characters.      │
     │ Punchy and concise.                                                     │
     │ 3. HASHTAGS: Exactly 20 hashtags relevant to this article, sorted from  │
     │ most popular/commonly used to least popular. List them space-separated  │
     │ on one line, each starting with #.                                      │
     │                                                                         │
     │ Article:                                                                │
     │ {article}                                                               │
     │                                                                         │
     │ Respond using exactly this format:                                      │
     │ LONG_FORM:                                                              │
     │ <caption here>                                                          │
     │                                                                         │
     │ TWITTER:                                                                │
     │ <caption here>                                                          │
     │                                                                         │
     │ HASHTAGS:                                                               │
     │ <#tag1 #tag2 ... #tag20>                                                │
     │                                                                         │
     │ 4. Response Parsing                                                     │
     │                                                                         │
     │ Parse the plain-text response using regex/split on LONG_FORM:,          │
     │ TWITTER:, HASHTAGS: markers to extract each section.                    │
     │                                                                         │
     │ 5. UI/UX Details                                                        │
     │                                                                         │
     │ - Loading spinner / disabled button while waiting for Ollama            │
     │ - Copy-to-clipboard button on each caption and the hashtag list         │
     │ - Minimal, clean styling (CSS embedded in the HTML file)                │
     │ - Error message display if Ollama is unreachable                        │
     │                                                                         │
     │ 6. CORS Note (important)                                                │
     │                                                                         │
     │ Browsers block requests to localhost from file:// URLs by default. To   │
     │ run the file directly, Ollama must allow cross-origin requests:         │
     │ - Set env var: OLLAMA_ORIGINS=* before starting Ollama                  │
     │ - OR serve the file via a local server: python -m http.server 8080      │
     │ - Add a note in the UI explaining this if the request fails             │
     │                                                                         │

     │ 3. Open index.html in a browser (or via python -m http.server)          │
     │ 4. Paste sample caption examples and an article                         │
     │ 5. Click Generate — confirm:                                            │
