Setup note: If captions fail to generate, Ollama may be blocking browser requests. Start Ollama with: OLLAMA_ORIGINS=* ollama serve — or on Windows, set the environment variable OLLAMA_ORIGINS to * before launching Ollama. You can also serve this file via python -m http.server 8080 and open http://localhost:8080.
